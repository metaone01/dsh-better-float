# 插件界面国际化

插件通过宿主的 `ctx.locale` 服务读取 Language 设置，不维护第二套语言偏好。
在 `betterFloat` 命名空间注册 `en`、`zh` 词典；语言标签解析、自动语言选择和其他语言的回退链由宿主负责。
对于宿主没有对应译文的语言，最终回退到英文。新增语言可以向此命名空间贡献对应词典。

覆盖快捷键名称、选择器提示、窗口按钮的 tooltip 和 `aria-label`、窗口总览与空状态、
召回及放置标签、预览失败提示、媒体兼容性警告和提取/还原错误的说明。
元素名称、DOM 标识、用户内容及原始异常信息不翻译。
选择器提示按操作分组，方向键与 Esc 使用圆角键帽，鼠标左键、拖动与滚轮使用内联 SVG 图标。
`↑ / ↓ / 鼠标滚轮` 调整选择层级：向上选父级，向下选子级；滚轮图标具有本地化文字提示。
提示栏在窄屏自动换行，切换语言或拖动状态时更新，普通指针移动不重复重建。
控制台中的开发诊断信息和底层 capture 数据不是界面文案，不纳入词典。

切换语言会立即刷新已打开的面板、警告、选择器和窗口总览，不重建窗口或中断当前操作。
界面关闭时解除订阅；插件卸载时清理窗口和选择会话并还原提取的内容。
直接使用底层面板或选择器函数且未传入 `messages` 时，保持原有英文默认行为。

词典与宿主服务的最小类型定义位于 `src/shared/i18n.ts`。
`zh` 词典必须实现全部英文键，缺失键会在 TypeScript 检查时失败。

验证：

- `npm run check`：包含词典键、插值参数、英文回退、动态快捷键名称及卸载清理回归。
- `npm run check:i18n:browser`：在独立、隐藏的 Electron 窗口中验证真实 DOM 与语言切换。
  不安装插件、不更改宿主设置，也不依赖正在运行的 DSH 调试端口。
